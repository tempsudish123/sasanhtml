Welcome to Day 1 of HTML

This is your first webpage. HTML stands for HyperText Markup Language.

HTML is used to structure content on a webpage, like headings, paragraphs, links, and images.

Basic HTML Tags

  • <h1> to <h6> - headings
  • <p> - paragraph
  • <a> - links
  • <img> - images
  • <ul> and <li> - lists

Simple HTML Example

<!DOCTYPE html>
<html>
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
    <p>This is my first webpage.</p>
  </body>
</html>

What You Learned Today

You learned that a webpage is built using HTML tags and that each tag has a purpose.
